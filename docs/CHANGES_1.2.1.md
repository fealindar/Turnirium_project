# Turnirium 1.2.1 — исправление посева группового плей-офф

Исправление поверх исходников версии **1.2.0**. Структура базы данных и API не меняются.

## Посев плей-офф

- Участники формируются из итоговой таблицы **каждой группы**, сохраняя её места и число выходящих.
- В плей-офф применяется отдельный **зеркальный посев** по спортивным местам: первые номера разных групп располагаются в разных ветвях по возможности, а ранние раунды сопоставляют высокие места с низкими.
- Участники одного места из разных групп могут переставляться друг с другом ради предотвращения повторных встреч внутри одной группы в первом раунде и отдаления возможных реваншей.
- Свободные слоты **BYE** предоставляются участникам с наиболее высокими номерами посева (например, при двух группах по три выходящих оба победителя сразу проходят во второй раунд).
- Исключённый участник пропускается с сохранением своего места в таблице: другой участник его группы не превращается искусственно в «первое место».
- Алгоритм детерминирован, не зависит от клубов и городов и ограничивает объём локальных перестановок на больших категориях.
- **Генерация самих групп и жеребьёвка обычной олимпийки не изменялись.** Клубы/города по-прежнему учитываются при формировании групп.

## Ручное редактирование

- Исправлены отсутствующие импорты `Area` и `MatchEvent` при перестройке сетки до начала реальных поединков.
- Добавлена проверка размера списка слотов. Ручная перестройка после начала хотя бы одного реального боя по-прежнему запрещена; автоматические BYE не блокируют перестройку.

## Применение

В корне исходников 1.2.0:

```bash
git apply --check /путь/к/Turnirium_1.2.0_to_1.2.1.patch
git apply /путь/к/Turnirium_1.2.0_to_1.2.1.patch
```

Патч следует применять **только к исходникам 1.2.0**, не к уже изменённым вручную файлам. Для новой установки можно распаковать полный ZIP 1.2.1.

Миграция SQLite не нужна. Перед обновлением рабочей системы рекомендуется сохранить резервную копию базы данных. **Существующие ранее сформированные сетки не перестраиваются автоматически**, чтобы не менять начавшийся турнир; новые правила действуют при новой генерации плей-офф.

## Проверки

```bash
python -m pytest -q -W error
python -m compileall -q app tests
for file in app/static/*.js; do node --check "$file"; done
```

Добавлены тесты: две/три/четыре/шесть/восемь групп, все участники выходят, неполная группа, сохранение места исключённого, BYE, ручная перестройка с/без BYE, защита уже начавшихся боёв.
