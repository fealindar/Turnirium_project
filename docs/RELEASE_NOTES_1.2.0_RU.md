# Turnirium 1.2.0 — что нового

Выпуск объединяет улучшения предыдущих версий 1.1.6 и 1.1.7.

- **Площадки.** Теперь можно назначать категорию или группу сразу на одну или несколько площадок через единое меню «Распределить по площадкам». Бои больше не назначаются автоматически при создании единственной площадки.
- **Балансировка очередей.** Поединки распределяются равномернее. Кнопка «Оптимизировать очереди» помогает выравнивать загрузку площадок во время турнира, не затрагивая идущие бои.
- **Секретарь.** Победа по счёту и ничья фиксируются одним нажатием. Для технических поражений, дисквалификаций и других санкций доступно отдельное подтверждение завершения, чтобы можно было отметить нарушения у обоих бойцов.
- **Обоюдные поражения.** Добавлены обоюдные технические поражения, дисквалификации, поражения по предупреждениям и выбытия. Счёт проведённого боя сохраняется для турнирной статистики даже при отсутствии победителя.
- **Группы + плей-офф.** Можно вывести в плей-офф всех участников группы.
- **Швейцарская система.** Дополнительный тур можно добавить уже после начала соревнования.
- **Досрочное завершение.** Категорию можно завершить раньше и рассчитать итоговую таблицу по состоявшимся боям.

**Важно:** обновление не требует изменения структуры базы данных. Перед установкой рекомендуется создать резервную копию.
