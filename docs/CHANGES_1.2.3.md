# Turnirium 1.2.3 — горячие клавиши секретаря

Основа: **1.2.2 с хотфиксом зеркалирования табло**. Миграция SQLite не требуется.

## Интерфейс

- В левом верхнем углу экрана секретаря вместо ссылок расположены три кнопки: **Организатор**, **Табло**, **Горячие клавиши**.
- Список клавиш открывается независимо от текущего боя, служит справкой и позволяет менять сочетания нажатием на текущую клавишу.
- Модальное окно ждёт действительную клавишу/сочетание, предупреждает о дублировании или зарезервированной комбинации. Пока допустимое сочетание не получено, **Сохранить** неактивна. Доступны отмена и сброс всех сочетаний с подтверждением.
- Настройки хранятся в `localStorage` браузера рабочего места, без отправки на сервер. При недоступном хранилище текущая сессия продолжает работать; после перезагрузки могут вернуться значения по умолчанию.

## Сочетания по умолчанию

| Действие | Клавиша |
|---|---|
| Старт / пауза времени | Пробел |
| Добавить / убрать 10 секунд | `+` / `-` (включая NumPad) |
| Красному +1 / +2 / −1 / −2 | `Q` / `W` / `A` / `S` |
| Синему +1 / +2 / −1 / −2 | `P` / `O` / `L` / `K` |
| Отмена последнего действия | `Ctrl+Z` |
| Следующий бой | `Ctrl+Enter` |

Веб-интерфейс обрабатывает `KeyboardEvent.code`, т. е. физическую клавишу, вне зависимости от русской/английской раскладки. Буквенные команды не зависят от регистра; при этом можно явно назначать сочетания с `Shift`, `Ctrl`, `Alt`. Известные системные и браузерные комбинации запрещены при переназначении. Повторы клавиш при удерживании, ввод в полях и открытые окна не вызывают команд боя.

## Сервер и турнирные правила

- `POST /api/matches/{id}/timer/adjust` с телом `{"seconds": 10}` либо `{"seconds": -10}`: коррекция времени с сохранением состояния работающего таймера, пересчётом его ревизии и времени автоматической остановки. Значение ограничено 0…86400 секунд; при уменьшении до нуля таймер останавливается.
- Остальные клавиши вызывают **существующие обработчики кнопок секретаря**, поэтому сохраняются их проверки (включая запрет перехода к следующему бою до фиксации результата).
- Изменения счёта доступны только в рамках списка кнопок конкретной категории. Для **новых категорий** по умолчанию теперь есть `−2`; старые категории/шаблоны в базе не изменяются. Если изменение не разрешено правилами, интерфейс показывает предупреждение, а значения не меняются.
- Изменён только экран секретаря и стандартные правила для новых категорий. Формирование групп, посев плей-офф и другие турнирные процессы не затронуты.

## Установка и тестирование

Остановить программу, сделать резервную копию каталога данных/SQLite; использовать архив исходников 1.2.3 или применить патч к **исходникам 1.2.2 после board-mirror хотфикса**. Перезапустить и обновить уже открытые вкладки секретаря один раз.

Проверено: полный набор `pytest`, `compileall`, `node --check`, а также сценарии Chromium — отображение окна, назначение/конфликт сочетаний, работа команд счёта, таймера и следующего боя. Физическая русская раскладка тестировалась генерацией событий с русскими символами и соответствующими `code`; отдельного аппаратного теста на нескольких клавиатурах не было.
