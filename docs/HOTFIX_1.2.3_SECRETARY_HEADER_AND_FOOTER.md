# Turnirium 1.2.3 — хотфикс навигации и нижней плашки

**Версия приложения остаётся 1.2.3.** Хотфикс применяется к полному исходному архиву версии 1.2.3. Миграция БД не требуется.

## Изменения

- В интерфейсе секретаря бренд (эмблема и название приложения) теперь слева; справа кнопки идут в порядке «Горячие клавиши», «Организатор», «Табло». Переключатель «Отзеркалить табло» остаётся по центру на широком экране. На узких экранах применена адаптивная раскладка без перекрытий.
- У кнопки закрытия справочника горячих клавиш заменён текстовый крестик на векторный значок SVG. Добавлены состояния наведения и фокуса для работы с клавиатурой, доступная подпись сохранена.
- Общая нижняя плашка на страницах организатора, секретаря, табло и общего экрана показывает название приложения, номер фактической версии и название клуба (если задано). При отсутствии названия клуба плашка всё равно показывает название приложения и версию. Настройка `show_footer_branding: false` продолжает скрывать плашку.
- `/api/branding` дополнен полем `version`, полученным из `app/version.py`. Прочие значения конфигурации не изменены.
- Уведомления (`toast`) теперь находятся **над** нижней плашкой: отступ рассчитывается исходя из её реальной высоты, пересчитывается при отображении уведомления и изменении размера окна. Анимация ограничена прозрачностью, чтобы уведомление не проезжало сквозь плашку.

## Проверки

- `pytest`: 146 тестов (включая новые регрессионные проверки).
- `node --check` для изменённых JavaScript-файлов; `compileall` для Python.
- Chromium: ширины 360, 480, 570, 750, 980, 1024 и 1440 пикселей, порядок навигации, работа окна горячих клавиш, взаимное расположение нижней плашки и уведомления, в том числе при длинном названии клуба и без клуба.
- Применимость патча проверяется сравнением с чистым архивом 1.2.3.

## Обновление

Из каталога исходников 1.2.3:

```sh
git apply --check Turnirium_1.2.3_UI_hotfix.patch
git apply Turnirium_1.2.3_UI_hotfix.patch
```

Перезапустите приложение и обновите открытые страницы (один раз). Механизм хеширования ресурсов в существующей версии сам обновит ссылки на изменённые CSS и JavaScript.
